# Analysis scripts

Scripts that produced the scores, tables and figures in `01`–`03` (copied from the operator workspace; paths in
them point at that workspace). Main ones: `score.py`, `ground_truth.py`, `peer_contrasts.py`, `mask_stream.py`,
`collect_and_audit.py`, `build_protocol.py`, `figures.py` (pilot, also in `01/scripts/`); `q27_build.py`,
`q27_score.py`, `gemma_build.py`, `gemma_score.py`, `ft_build.py`, `ft_score*.py`, `figure3.py` (held-out tests and
framework probe); `score_small.py`, `round_compare.py`, `signature.py`, `sig_table.py`, `fig_signature.py`,
`model_profile.py`, `r3_build.py`, `nlp_stats.py` (Qwen3-4B rounds); `alignment.py`, `fig_alignment.py`,
`seq_overlap.py`, `stats_strength.py` (03); `merge_scores.py`, `fig_general.py` (05); `run_codex_designer.sh`,
`run_codex_once.sh` (Codex designer invocation).
